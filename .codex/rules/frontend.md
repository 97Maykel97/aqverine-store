# Правила frontend

- Используйте SCSS Modules; избегайте неглобальных стилей компонентов без scope.
- Создавайте адаптивный UI, доступный с клавиатуры: семантические элементы, видимый focus и понятные labels.
- У каждого асинхронного экрана и mutation должны быть состояния loading, error и empty.
- В формах используйте React Hook Form с Zod-валидацией и доступными сообщениями об ошибках.
- Не переносите бизнес-авторитет в UI state: источником истины остаются ответы сервера.
