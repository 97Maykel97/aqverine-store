# Правила качества

- Вносите минимальное целостное изменение, сохраняющее документированные границы и инварианты.
- Запускайте релевантные форматирование, проверки типов, lint, тесты и browser verification.
- Не подавляйте ошибки без документированной причины.
- Делайте пользовательские ошибки полезными и безопасными.
- После реализации обновляйте затронутые docs и `docs/progress.md`.
- До передачи проверяйте diff на secrets, посторонние изменения и сломанные контракты.
- Перед передачей существенных изменений выполните `npm run lint`, `npm run typecheck`, `npm run test:run` и `npm run build`; сообщите о недоступных или упавших командах.
- Для изменений интерфейса запустите приложение и проверьте затронутый сценарий в браузере.
