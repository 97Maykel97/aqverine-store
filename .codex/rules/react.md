# Правила React

- Делайте компоненты узко сфокусированными и собирайте UI из частей feature.
- Используйте локальное состояние только для локального взаимодействия; server state храните в API/query-слое.
- Не используйте effects для производных значений или серверной авторизации.
- Используйте стабильные ключи списков и очищайте подписки, таймеры и обработчики событий.
- Сначала используйте семантический HTML и доступные labels, затем ARIA.
