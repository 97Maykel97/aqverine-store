# Схема базы данных AQVERINE

Это контракт будущей Prisma schema. Миграции пока не созданы.

| Модель | Назначение |
| --- | --- |
| `User` | Идентичность пользователя Supabase и роль `user` или `admin`. |
| `Profile` | Профиль покупателя, связанный с `User` один к одному. |
| `Product` | Карточка товара с уникальным `slug` и архивированием. |
| `ProductVariant` | Вариант цвет+размер с отдельным остатком. |
| `ProductImage` | Медиа товара и ключ объекта Storage. |
| `Cart` | Серверная корзина авторизованного пользователя. |
| `CartItem` | Количество варианта в корзине; уникален по `(cartId, variantId)`. |
| `Order` | Заказ, суммы которого хранятся в integer minor units. |
| `OrderItem` | Неизменяемый snapshot названия, цены, цвета и размера. |
| `Payment` | Попытка оплаты через провайдера. |
| `PaymentWebhookEvent` | Идемпотентность и аудит webhook по уникальному ID события. |

Деньги никогда не хранятся в floating point. Удаление товара не должно портить историю заказов. Изменение схемы требует Prisma migration и обновления этого документа.
